# C12 边界任务：无技术止损，只能设资金止损

**结论：能做计划，但不能按正常技术计划执行，必须降级。** 找不到技术止损→资金止损、轻仓或回避（原书边界）。

| 项目 | 计划内容 |
|---|---|
| 浪级 | 浪级不足以支撑技术止损，计划状态=观察（待确认） |
| 结构 | 关键点无法回指浪的起止点，标“未确认”，不得编造结构 |
| 势 | 只写候选方向，不据此重仓 |
| 入场 | 保留候选入场，但须待结构给出可回指极值后再执行；否则不进场 |
| 止损 | 仅资金止损（按账户可承受亏损反推），标“约定”，不得冒充技术止损 |
| 目标 | 下一级结构结束条件；结构未定则标待确认，不用固定百分比硬填 |
| 仓位 | 降为轻仓，股数按资金止损距离与风险上限反推；禁止重仓 |
| 失效条件 | 资金止损触发即离场；结构重标后原计划作废，重新走八步 |

处理：先补关键点/浪级数据；仍找不到技术止损→回避或只做观察计划。

风险提示：资金止损与结构无关，易被正常波动、跳空、涨跌停打穿（ce18/ce19警告无技术止损下单与固定3～5点资金止损）；滑点、停牌可使实际亏损超预算；资金止损不得用来放大仓位；结构多解时回避优先。
