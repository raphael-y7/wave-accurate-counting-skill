# C7 正常任务：下降三角形破位做空

**输入与定性**：上证 2566.53→2952.04 反弹，内部标为 A6-B6-C6。上边界自 2952.04 向下倾斜至 C6 高点 2924.45，下边界为 2566.53 水平线，构成下降三角形。位置属中浪(B)二次分解中的反弹，非推动浪；下破 2566.53 即确立反弹结束、中浪(C)继续。

**方向**：按“跟随 b 浪、即 a/c 反方向”，B6 向下，故向下突破；破 2566.53 确认。

**目标**：三角形前为反弹浪，目标不是 1:1，而是与反弹对应的中浪(C)调整结束；垂直高度 385.51 点仅作参考，按 1:1 粗算约 2181，只能算最浅参考，不能替代结构目标。中浪(C)终点事前不可知，只能逐级用结束条件确认，且可能下移。

**止损**：突破后空单止损放 C6 高点 2924.45 上方 1～2 点（约 2925.5～2926.5），距 2566.53 约 359 点（约 14%），风险大，故只可轻仓；作者要求能承受反弹至 2924.45 不爆仓。

**仓位**：杠杆品种（股指期货等）轻仓 5%～10%；股票不能做空，持仓者应减仓或离场，融券亦按轻仓。若破位后反抽站回 2566.53 上方，空单失效。

**数据不足**：A6/B6/C6 的次一级细分未给出，无法核验 3-3-3-3-3 或 5-3-5-3-5，只能按书中形态与破位定性；目标点位不可预先量化。
