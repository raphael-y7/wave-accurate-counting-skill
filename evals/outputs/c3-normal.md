# C3-normal：6124 顶部捕捉

**结论：** 日线大浪3五浪在6124完成、具备结束条件，后市转大浪4调整。顶部按“推动浪最后一浪结束条件”给区域，不把6124当精确预测点。

| 项目 | 内容 |
|---|---|
| 级别/结构 | 日线大浪3；1/3/5为次一级五浪，6124处第5浪末端；6124同时为年线iii、月线小浪3、周线中浪3终点，四级共振 |
| 顶部区域 | 6124上方0～100点（6124—6224，书中案例区） |
| 入场 | 6124—6126轻仓分批；更高批次须另设极值止损 |
| 止损 | 6126（极值上方2点） |
| 短线目标 | 细浪{c1}调整结束 |
| 波段目标 | 小浪级A、B、C调整结束 |
| 中长线目标 | 中浪级(A)、(B)、(C)调整结束；5800以上可分批中长线空 |

**不确定性与失效：** 顶部区与止损存在冲突：若在6126以上入场，6126止损反在入场价下方，风险不可控；按卡规则应把可执行区收窄到6124—6126附近轻仓分批，或改用结构止损并降仓。书中另处写“6124以上1点”，与6126有1点差异，本次取6126并标注。延长浪未确认：若后市同级推动浪上破6124，原顶作废、顶部上移；第5浪末端不得重仓。三档目标均属结构目标，不是固定点位，书中并未给出具体目标价。
