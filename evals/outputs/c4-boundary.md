# C4-boundary

**结论**：不能按“底部捕捉”原流程做多。b浪已上破a浪起点，调整转为上倾，本卡作废；但也不是转手在b浪里追多。

**应改用的流程**：
1. 用逐级数浪重标起点与级别，确认b上破是调整内部反弹还是新推动浪；
2. 用调整模式库判上倾结构类型（如锯齿A-B-C、双节棍上倾），不再套“等b接近a起点”的下倾剧本；
3. 用结束条件判定等c浪回撤（相对上倾b）具备/确立结束；
4. c浪确立结束后再做多，止损放c浪低点下1～2点，目标下一级推动浪结束；
5. 若再上破b浪高点，按推动浪/上倾延长处理，仍不追高。

**纪律**：c未确立只能轻仓试单；旧止损（原c低点外）已无效，必须重设；原“c浪幅度大于a浪”目标失效。无法确认上倾结构时等确认或不做。

**参照**：本书c04段{b}上破小浪1高点1746.61至2250.32后，并未立刻做多，而是等{c}结束于2084才买入，止损1～2点，目标小浪3。上倾结构同样要等c，不得把b的上破当买点。

**数据缺口**：题设未给a、b具体点位、b的分解层级和当前c位置，无法定价，不编点位。
