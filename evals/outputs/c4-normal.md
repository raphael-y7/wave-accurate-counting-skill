# C4-normal

**结论**：可以抄底，但只到“具备结束条件”档，轻仓试单；不能重仓，须等“确立结束”再加仓。

- 级别链：年线细浪{iv}=年线微浪(a)(b)(c)；(a)6124→1665，(b)1665→3478，(c)3478→2319.74。2319.74为最小可见c浪底，且同时具备年线{iv}结束条件。
- 入场分两档：微浪(c)内部三浪闭合、出现结束信号→试单；上破微浪(c)反弹高点或次一级三浪确立→加仓。仓位试单≤两成，加仓后仍按逆市单上限控制。
- 止损：2319.74下1～2点（上证约2317～2318），破位即结构失效；不用固定百分比。
- 目标：年线{v}推动浪的结束条件，不是固定盈利比例；需后市走出推动浪后逐级确认，题设数据给不出目标点位。
- 失效条件：下破2319.74；年线(b)再分解、底部下移；c浪后只走反弹、不走推动浪（未确立）；三角形强势调整假设被破坏。
- 数据缺口：题设只有年线/微浪级点位，无月线以下内部数据，不能缩到亚微浪；1～2点对上证指数过窄，A股跳空/T+1下须按品种点值放宽或不做。
- 案例警示：该段后市下破2319.74至1849，年线(b)被判定分解，止损会触发。“具备”不等于“确立”，必须靠止损兜底。
