# C2-boundary：具备结束后只走反弹

**结论：不能判定已经结束；原c浪低点只能算候选结束点，结束点暂不下移，待破位再下移。** “具备结束条件”只说明最低构成已满足；后市本应运行推动浪，实际却只走出反弹/三浪，说明该调整尚未结束，或结束级别不够。

**处理：**
1. **状态降级：** 由“具备结束”降为“未结束／未确立”，原c浪低点只算“候选结束点”。
2. **结束点下移：** 只有后市再下破原c浪低点，才按“原b改a、原c改b、a0改c”重标，新结束点在新的c浪低点；未破之前不得提前宣布下移。
3. **反弹定性：** 若反弹连c浪高点都未上破，只能视为调整中的b浪或反弹，不构成做多条件；若反弹上破a浪起点，则转上倾结构，另按上倾调整处理；若上破c浪高点但内部只是三浪，仍不构成推动浪确认。
4. **复杂化：** 反弹内部再分解时，交复杂调整能力，不硬判结束。

**失效/标的未确认：** 调整结束这一标的未确认，结束点未确认；在推动浪结构出现前，不给“已结束”结论。
