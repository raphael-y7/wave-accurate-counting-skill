# C8 边界任务：X 浪只有两浪，还能判组合结构吗

**结论：不能判组合结构，降级为单层调整观察。**

理由：组合b（X浪）必须是以组合a的a浪为基础的同级完整三浪；少一个细分浪，级别与三浪构成都不成立。两浪的“X”只是未完成结构，不能把 a1b1c1 合并成组合a，也不能预期 a3b3c3。

**应改判**：退回单层调整。a1b1c1 仍只是小浪2“具备结束条件”的候选；后面的两浪按 b1（或 b 浪）再分解处理，属同一调整浪内部延伸，不构成组合。若第三浪随后完成并上破 a2 高点，才可重新确认组合b；若先下破 c1 低点，则单层调整延续或组合失败。

**动作**：撤销组合标注；不按“组合c结束”做多；已有低位多单减仓，止损放 c1 低点外 1～2 点；空仓者不做，等第三浪闭合且上破 a2 高点再评估。若参与反弹只能轻仓（杠杆≤5%），不得加仓。

**数据不足**：缺 X 浪内部标签与时间周期，无法判断是“未完成三浪”还是“b 浪再分解”；上述改判需后续关键点确认，不能提前定性。
