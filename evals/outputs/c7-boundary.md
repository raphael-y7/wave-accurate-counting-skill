# C7 边界任务：C 浪末端 c0 上破 c2，能否追多

**结论：不能追多，降级为观察。**

理由：
1. 位置：三角形作 c 浪时是“结束结构”，c0 是最后一脚；c0 结束即大一级 C 浪结束，突破发生在调整末端，不是新推动浪起点。
2. 方向规则：三角形突破本应跟随 b 浪；C 浪末端结构已完整，c0 上破 c2 高点常是假突破。书中明确：C 浪末端或 c 浪已完整时，突破多为假突破，禁止追单。
3. 目标：c0 上破 c2 后，与 a 对应的 c 浪目标已在眼前，上方空间有限，追多风险收益比差。
4. 确认不足：c0 是“具备结束条件”还是“确立结束”未给；若仅具备条件，突破更不可信。

**动作**：不追多；已有低位多单在 c0 上破 c2 后减仓或锁盈；空仓者等回抽不破 c0 低点再议，或等上破更大一级 C 浪起点并回踩确认。激进者最多轻仓试单（杠杆≤5%），止损 c0 低点外 1～2 点，且不因其上破 c2 而加仓。

**数据不足**：C 浪级别、c0 内部五浪或三浪、时间周期均未给，无法确认“末端”是否成立；若后续推动浪上破 C 浪高点并站稳，才可改判，不能预先追。
