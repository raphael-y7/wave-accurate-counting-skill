# 决策规则速查 — 精准数浪——波浪理论内部结构分析及买卖点位把握

| 能力 | 一句话规则 |
|---|---|
| 逐级数浪与级别定位 | 先定级别与结构，再谈方向：五浪走完升级，1/3/5必须次一级仍是五浪，锯齿允许缺陷。 |
| 具备结束条件与确立结束判定 | 具备结束条件只可试单，确立结束才加仓；a0上破c高点/上破a起点/后市结构验证三选二。 |
| 推动浪顶部捕捉（含延长浪） | 把推动浪顶部逐级锁到最小浪级的最后一浪，止损极值外1～2点，延长浪则顶部上移。 |
| 调整浪底部捕捉（含 c 浪交易） | 把调整浪底部逐级缩到 c 浪的微浪(c)/亚微浪 c，止损极值下1～2点，b 浪再分解则底部下移。 |
| 调整结构模式库（四模式+剪刀/镰刀/双节棍+强弱） | 先归四基础模式，再识别剪刀/镰刀/双节棍；用 b 浪位置与 0.382/0.5/0.618 判强弱。 |
| 复杂调整与浪中浪 | 浪中浪只在两个复杂结构关键点同时被突破时追单；只破一个关键点不重仓。 |
| 三角形识别、方向/幅度与两段式交易 | 三角形方向跟随 b 浪；两个时机=完整 b 浪结束与颈线突破；幅度看对应 c 浪结束。 |
| 组合结构的形成、演变与三种未来 | 组合结构按 a/b/c 三组三浪合并与移位；c1/c3/c5 做多，c2/c4 短空，c 结束抓底。 |
| 顺势四分法与仓位/确定性管理 | 先问顺哪种势，再按确定性与止损距离配仓位；止损空间大于目标空间就不做。 |
| 大小级别一致性与支撑阻力/止损迁移 | 小级别服从大级别；浪的起止点就是支撑阻力，结构变则止损与仓位同步迁移。 |
| 中长线/波段/短线策略与延长浪盈利管理 | 按推动浪级别选周期；延长浪先设保底目标，确认后再持到延长浪结束。 |
| 交易计划整合 | 按浪级→结构→势→入场→止损→目标→仓位→失效八步生成可复核交易计划。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
