# 调整浪底部捕捉（含 c 浪交易）

## R — 原文

> 再看图1-19 中细浪级 {c3} 浪，细浪级 {c3} 浪是由微浪级（a）、（b）、（c）三浪组成，这是通过调整浪级别间的关系推断出来的，那么细浪级 {c3} 浪的底部我们就可以缩小至微浪级（c）浪这个波动幅度相对比较少的范围里。

— 出处：第一章第五节二（调整浪的底部捕捉），图1-19

## I — 自述

1. 推动浪的起点就是调整浪的底；抄底不是猜一个点，而是判断某一级调整浪在哪里结束。
2. 先由调整浪级别推出内部三浪：小浪2→细浪{a}{b}{c}，{c}→微浪（a）（b）（c），再拆到亚微浪。
3. 拆小级别是为了把底压成窄幅区；级别越小，止损越近，试单才有意义。
4. 最小 c 浪“具备结束条件”只算可以结束，只能轻仓试单；出现“确立结束”才加仓。
5. 止损放在该最小 c 浪确立结束低点下 1～2 点，不用固定百分比；被打掉就说明结构判断失效。
6. 目标是下一级推动浪（如小浪3）的结束条件，不是随意定的盈利百分比。
7. b 浪是最大变量：b 再分解，c 的起点与底部就随之下移。
8. 分工是验证 a 浪、放弃 b 浪、交易 c 浪：a 浪高低点已给出关键位，b 浪易分解；等 b 接近 a 起点，止损幅度可量化，c 浪幅度通常大于 a 浪。
9. 但 c 浪交易本质是逆市单，不能因为“利润可观”就重仓，c 浪仍可再分解。
10. 若 b 上破 a 浪起点，调整转为上倾，本卡作废，应改顺上倾结构做多。

## A1 — 应用示例

- **c03 上证指数日线小浪2（2006-12）**：小浪1 自 1541.4 涨至 1746.61；小浪2 为细浪 {a}{b}{c} 剪刀式，{a} 未再分解，{b} 一次分解后再分解。{c} 不再分解、三浪结束条件成立时，小浪2 具备并确立结束，买入；止损 {c} 低点下 1～2 点，目标小浪3。结果小浪3 自 2006-12-11 的 2084 涨至 2007-01-04 的 2847，涨幅 36.6%。
- **c20 现货黄金 60 分线（2015-05-14）**：1227.11 具备日线一浪反弹结束条件后，60 分线走 a1-b1-c1 下倾，c1 具备结束条件；b2 回调接近 a2（c1）低点时做多 c2，止损 a2 下 1～2 点，目标 c2 反弹结束。实际 c2 短线反弹利润可观，书中未给具体点数与盈亏金额（未说明）。
- **c14 上证指数年线（原书未标日期）**：1665→3478→2319.74；2319 具备年线微浪（c）及年线细浪 {iv} 结束条件，且被视为三角形强势调整。按计划在 2319 具备/确立结束时做多，止损 2319 下 1～2 点，目标年线 {v}。结果后市下破 2319 至 1849，书中判定年线（b）已分解，2319 不是终点；若已买入，止损会被触发（成交结果未说明）。这说明“具备结束条件”之后仍必须靠止损兜底。

## A2 — 未来触发

1. “这里能抄底吗 / 跌到位了吗”（Can I bottom-fish here?）——要回答调整级别、最小 c 浪和止损距离。
2. “调整结束了吗 / c 浪走完了吗”（Has the correction ended?）——先分“具备”还是“确立”。
3. “b 浪还没走完吧 / b 浪会不会再分解”（Is the b-wave still unfolding?）——要回答底部是否下移。
4. “目标看到哪 / 下一浪是什么”（Where is the target?）——目标指向下一推动浪结束。
5. “止损放哪 / 放多少点”（Where do I put the stop?）——极值外 1～2 点，按品种点值换算。

## E — 执行步骤

**输入契约**：标的、周期、至少两级嵌套数据（理想为日线+60 分线）、调整浪 a/b/c 关键点、当前价、品种点值；给出账户可承受止损更好。缺一级数据→停在可用级别并声明，不得假称已缩到亚微浪。

1. **定级推三浪**：确认调整级别（如小浪2），按级别关系推出内部 {a}{b}{c}，标出 a、b 高低点。完成标准：写出“级别→内部三浪”链条，三个角色无缺。
2. **验证 a 浪**：判 a 浪是单浪、三浪还是五浪，按 a 结构给 c 浪定性（a 单→c 单；a 五浪→c 五浪；a 三浪→c 三浪（3-3-3）或五浪（3-3-5））。完成标准：a 结构类型 + c 预期结构 + a 起止点关键位。
3. **放弃 b 浪**：不交易 b；等 b 反弹接近 a 起点，计算可接受止损幅度，检查 b 是否再分解；b 上破 a 起点→判停，转上倾做多。完成标准：b 落点、止损距离数值、是否分解三项齐全。
4. **逐级缩 c**：{c}→微浪（a）（b）（c）→亚微浪 a/b/c；把底压到最小 c 浪；若 b 再分解，底部下移到新的 {c3} 并重标。完成标准：最小 c 浪极值 + 内部三浪状态 + 具备/确立结束条件。
5. **两档入场**：最小 c 浪仅“具备结束条件”→轻仓试单；出现“确立结束”（上破该级 c 浪高点/次一级三浪闭合）→加仓；c 浪是逆市单，不重仓。完成标准：试单与加仓各有价格触发，仓位档写明。
6. **止损/目标/失效**：止损=最小 c 浪确立结束低点下 1～2 点（按品种点值换算）；目标=下一推动浪（如小浪3）结束条件；失效=破止损、b 上破 a 起点、c 后只走反弹不走推动浪（结束点下移）。完成标准：止损价、目标价、失效条件可执行；止损空间大于目标空间则不做。

**分支/判停**：b 未分解且 c 不分解→标准底；b 再分解→底部下移，回步骤 4；b 上破 a 起点→上倾，判停；c 结束后只走反弹→未确立，结束点下移；数据不足→停在可用级别，放宽止损或不做。

**输出契约**：级别链、a/b/c 关键位、最小 c 浪区间、试单/加仓触发、止损价、目标价、失效条件、仓位档、数据缺口声明。

**完成标准**：所有价位可下单执行；底部区间来自最小 c 浪而非主观；止损距离≤可承受风险；目标有结构出处；b 分解与上倾分支均已写明。

## B — 边界

**反场景**：推动浪顶部、三角形突破、组合结构横盘、没有 a/b/c 可数的单边急跌、只有单一级别数据。

**作者警告**：具备结束条件≠确立结束（ce11）；B 浪位置不可重仓（ce20）；止损别设在 b 子浪极值外，否则会被分解打掉（ce27）；回避固定 3～5 点资金止损（ce19）；找不到技术止损位就不做（ce18）；交易 c 浪是逆市单，不能重仓（ce24）。

**盲点**：书中的案例是事后标注，实时识别难度被低估；1～2 点止损对 A 股个股跳空、涨跌停、流动性不足不适用；“目标=下一级结束条件”没有给出未达目标时的退出规则；“确定性高”没有量化标准。

**易混**：与顶部捕捉方向相反；与 end-conditions 是“用状态”与“判状态”的分工；与 correction-patterns 是“用模式”与“命名模式”的分工；与 complex-correction 是单层与嵌套的分工；与组合结构的区别是第一组三浪结束不等于整个调整结束（ce29）。

**A股适配**：T+1、涨跌停、跳空；指数点与个股价格点值不同，1～2 点须按品种波动单位换算。
