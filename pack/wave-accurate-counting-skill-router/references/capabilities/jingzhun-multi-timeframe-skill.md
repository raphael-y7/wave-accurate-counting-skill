# 大小级别一致性与支撑阻力/止损迁移

## R — 原文

> “浪形内部结构分析不但可以找到阻力位和支撑位，而且这种阻力位和支撑位相当准确有效，精确到一个点”……“小级别或小时间周期浪形结构分析要符合大级别或大时间周期浪形结构分析的变化和要求。”
>
> —— 陈晓东《精准数浪》第四章第三、四节；引自合并转写稿.md L4093、L4165（下同）

## I — 自述

这张卡处理多周期打架，顺序不能反。
先把大级别（年/月/周/日）当前浪级与浪段定下来，再把小级别结构放进去解释。
小级别五浪若落在大级别调整浪内部，只是锯齿反弹，不是反转；小级别只负责选点和止损。
支撑阻力不用均线或百分比，用浪的起点和终点，书中称可精确到一个点。
推动浪前高前低、调整浪a/b/c端点都是关键位，主次按当前结构定。
结构一变，关键位按新结构重定，旧位逐项核对是否失效，技术止损跟着迁移，仓位按新止损距离复算。
周期要匹配：中长线年/月，波段月/周，短线周/日；选点用日线，必要时60分细化（映射为操作约定）。
大级别本身未确立时，不得用“大级别”压死小级别，只能标多解、等待或轻仓。
输出只回答三件事：大级别方向、小级别许可、关键位与止损迁移。

## A1 — 应用示例

**例1（c21，现货黄金，历史案例）** 输入1142.58～1132.29日线。书中判：这段日线复杂演变在周线只是简单三浪反弹。执行：先定周线反弹，再到日线找点，不把日线复杂浪升级为周线推动浪。结果：仅作级别一致性例证，未说明交易结果。

**例2（c15，上证指数，历史案例）** 输入3478→2319→3187→1849。2319→3187有两种数法：三组三浪或剪刀式含双节棍上倾；2702是排除推动浪的最初信号。执行：未破2389/2319前保留推动可能，2702后按反弹处理，跌破2389/2319则确认反弹延续。结果：跌至1849，年线(b)分解为(a0)(b0)(c0)。

**例3（c17，上证指数，历史案例）** 输入95.79→6124，按年线数浪：{i}95.79→1559、{ii}1559→998.23（326为关键低点）、{iii}998.23→6124。执行：长线看年线、波段看月线，周/日只作选点。结果：6124结束年线{iii}，进入{iv}；书中认为2016年仍在{iv}。

## A2 — 未来触发

### 用户会在什么情境下需要这张卡？

1. 日线看多、周线看空，问听谁。
2. 问支撑/阻力在哪。
3. 结构演变后问止损/阻力是否跟着移。
4. 小周期突破问能否追。
5. 下单前问按哪个周期做。

### 语言信号（中英双写）

- “日线看多周线看空听谁的” / “daily bullish but weekly bearish, which wins”
- “支撑位在哪、阻力位在哪” / “where is support/resistance”
- “止损要跟着结构移吗” / “should I move my stop with the structure”
- “小级别突破了能追吗” / “small timeframe breakout, can I chase”
- “先看哪个周期” / “which timeframe should I use”

### 与相邻能力卡的区分

- 不做结构模式命名（剪刀/镰刀/双节棍/组合/浪中浪）→ 交 `correction-pattern-library`、`complex-correction-wave`。
- 不做仓位档与确定性分级 → 交 `trend-position`。
- 不做单笔顶部/底部入场 → 交 `top-capture`、`bottom-capture`。
- 不产出完整交易计划表 → 交 `trade-plan`。本卡只给方向、许可、关键位与止损迁移。
- 负例：“这段是剪刀还是镰刀”“这笔下多少仓”“现在能不能抄底”均不归本卡。

## E — 执行步骤

**输入契约**：标的、至少两个时间周期（年/月/周/日/60分）的K线、已完成的浪级标注与关键点、当前持仓（方向/成本/止损，可空）。缺大级别数据先问，不得用单一周期硬推。

1. **定大级别**：选最高可信周期，写出级别、浪段、方向；说不出标“未确立”。完成标准：一句话可复核。
2. **嵌入小级别**：把小级别放进大级别框架，逐段归属；小级别推动浪落在大级别调整内→改判锯齿。完成标准：每段有归属或标冲突。
3. **匹配周期**：按中长线年/月、波段月/周、短线周/日列周期表，选点日线/60分。完成标准：交易级别=目标级别。
4. **标关键位**：列主/次支撑阻力，逐项回指浪的起止点。完成标准：无来路的位置删除。
5. **迁移止损**：止损=所交易浪极值外1～2点；结构变则迁移并复算仓位（档位交 `trend-position`）。完成标准：止损对应现行结构，旧位逐项标注失效/保留。
6. **给许可结论**：输出大级别方向、小级别可做方向/级别、关键位、迁移触发。完成标准：冲突以大级别为准；大级别未定→多解/等待/轻仓。

**分支/判停**：大级别未确立→不用它压小级别，标多解，等关键点突破再判；小级别与大级别冲突→服从大级别，小级别信号只用于选点；结构升级/分解→回第4步重标关键位，再走第5步；只有一个周期或关键位无法回指浪的起止点→判停，补数据或放弃本卡结论。

**输出契约**：①大级别（级别/浪段/方向）；②小级别（结构/是否许可）；③周期匹配；④主次关键位及对应浪起止点；⑤止损及迁移触发；⑥结论（可做方向/等待/回避）。每项须有依据；不确定写“未确认”，不得用猜测填满。

## B — 边界

### 不要在以下情况使用此卡

- 只有一个周期、没有大级别标注：先补数据，否则“大级别”是编的。
- 用户只问某一段是什么调整模式：交模式库，不要用级别一致性替代模式识别。
- 用户要具体仓位比例或单笔入场价：交 `trend-position` / `top-capture` / `bottom-capture`。

### 书中警告的失败模式

- 用小级别或小周期结构对抗大级别（ce14）：小周期信号频繁，容易频繁反手。
- 级别标注混乱（ce15）：同一段用多套浪标，结束点越标越乱；应向上归并到大一级。
- 把锯齿当推动浪（ce08）：大级别调整/反弹内部没有推动浪，只有锯齿或3-3-5。
- 行情升级后不提升基础浪（ce26）：小级别八浪走完还按原级别数，会踏空或过早做空。

### 作者盲点（阶段 0 批判）

- 案例多为事后标注，“精确到一个点”遇跳空、涨跌停、流动性不足会被滑点破坏；书中未给跳空处理。
- “服从大级别”依赖大级别本身数对；大级别数错会带错小级别，书中无置信度评分。
- 周期映射来自指数经验，个股波动差异大，细浪级能否做波段需按标的调整。

### 易混

- 与 `correction-pattern-library`：本卡不命名剪刀/镰刀/双节棍，只处理级别从属与关键位。
- 与 `trend-position`：本卡说“许可/不许可”，不说“下几成”。
- 与 `trade-plan`：本卡是计划中的“级别与关键位”模块，不是完整计划。
