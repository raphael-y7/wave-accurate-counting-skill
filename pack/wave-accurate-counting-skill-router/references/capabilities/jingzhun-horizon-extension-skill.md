# 中长线/波段/短线策略与延长浪盈利管理

## R — 原文

> “单从推动浪级别来看，亚微浪级、微浪级只能做短线，细浪级有的可以做波段有的做不了波段，小浪级肯定可以做波段，中浪级和大浪级可以做中长线操作。”……“我们可以把预期的盈利空间起码调整至小浪5不演成延长浪的情况下小浪级B浪反弹具备结束条件之时”
>
> —— 陈晓东《精准数浪》第一章第十七节、第五章第二节五；引自合并转写稿.md L1843、L4590（下同）

## I — 自述

这张卡解决“拿多久、目标怎么移”。
先判当前推动浪级别，再决定持仓周期。
亚微/微浪只做短线；细浪看幅度决定能否波段；小浪可波段；中/大浪做中长线。
中线把日线拆到细浪/微浪，短线拆到微浪/亚微浪，必要时5分/60分。
仓位分中长线底仓、波段、短线三层，各层入场、止损、目标分开管理。
延长浪先按“不延长”设保底目标：同级三浪回调中的B浪反弹结束。
只有同级推动浪上破前高、内部确认延长，才改持到延长浪结束。
延长中延长再上移；未确认前不拿延长目标，也不加仓。
结构失败（如双节棍上破a4高点）按反手流程：止损原单、顺突破方向反手。
任何判断都要有出局点；看对延长不早下车，看错只损失保底前的利润。
输出周期选择、目标分层、延长/保底管理、反手条件。

## A1 — 应用示例

**例1（c08，上证指数，历史案例）** 输入6124具备大浪3结束条件。结构=后市大浪4；执行=6124上方0～100点抓顶做空，止损6126；短线目标细浪{c1}结束、波段目标小浪ABC结束、中长线目标中浪ABC结束，5800以上分批中长线空。结果：6124→4778完成中浪(A)，未说明单笔盈亏。

**例2（c16，上证指数，历史案例）** 输入1849.65→5178.19。结构=月线{a}{b}{c}反弹、整体周线5-3-5锯齿；{a}为周线五浪，{c}为周线终结倾斜三角形、每浪日线三浪。执行=按技术止损规则，{c}内部c5结束可抓顶、止损5178上方1～2点，或等年线(c)。结果=5178成为月线{c}终点并再具年线(b)条件，后市进入年线(c)调整。

**例3（c41，双节棍失败反手，示意图）** 输入a4-a0-b0构成双节棍条件。结构=若不下破a4低点反而上破a4高点，双节棍失败。执行=上破瞬间止损空单反手做多，止损a4或前一调整低点下1～2点，目标c5反弹结束。结果：示意图，未说明。

## A2 — 未来触发

### 用户会在什么情境下需要这张卡？

1. 问这笔拿中长线还是短线。
2. 已有浮盈，问延长浪还能不能拿、先出还是等。
3. 目标到了，问要不要上移。
4. 结构失败，问是否反手。
5. 中长线底仓与波段/短线单如何分层管理。

### 语言信号（中英双写）

- “这笔拿中长线还是短线” / “hold for the long term or trade short”
- “延长浪还能拿吗” / “is this an extension wave, can I still hold”
- “先出还是等” / “take profit now or wait”
- “目标要不要上移” / “should I raise my target”
- “要不要反手” / “should I reverse my position”

### 与相邻能力卡的区分

- 单笔入场交 `top-capture` / `bottom-capture`；浪级判定交 `wave-levels`；模式命名交 `correction-pattern-library`。
- 仓位比例交 `trend-position`；完整计划交 `trade-plan`。
- 本卡只输出周期选择、目标分层、延长/保底管理、反手条件。
- 负例：“哪里进场”“下多少仓”不归本卡；“这段是不是延长浪”需先由浪级/结束条件卡确认，本卡只处理确认后的持有与目标。

## E — 执行步骤

**输入契约**：标的、当前持仓（方向/成本/仓位层级）、浪级与结构状态、入场价、现止损、目标、账户风险约束。缺持仓或浪级先问，不猜。

1. **级别→周期**：亚微/微→短线；细→视幅度；小→波段；中/大→中长线。完成标准：写出级别、周期及理由。
2. **选细分层级**：中线拆日线细浪/微浪，短线拆微浪/亚微浪（必要时60分/5分）。完成标准：明确入场、出局所用级别。
3. **三层分账**：中长线底仓、波段、短线各列入场/止损/目标；只做一层则明说。完成标准：三层不混，仓位不重复计算。
4. **设双目标**：强势调整（上倾/三角/组合）先设保底目标=同级三浪回调B浪反弹结束；同级推动浪上破前高且内部确认为推动浪→改持到延长浪结束；延长中延长→再上移。完成标准：保底与延长两套目标及确认条件都写出。
5. **到价处理**：保底目标处未确认延长→出局/减仓；确认延长→止损上移至调整低点外1～2点并持有。完成标准：每个目标都有动作。
6. **失败反手**：结构失败（如双节棍上破a4高点）→止损原单、顺突破方向反手，止损突破前低/a4低点外1～2点，目标新结构结束。完成标准：反手点、止损、目标齐全。

**分支/判停**：只有信号无确认→守保底、不加仓；确认延长→上移；只是反弹→B浪结束出局；无法定级别→不做周期决策。

**输出契约**：层级/周期/结构依据/入场/止损/目标/延长处理/失效或反手，八列；每列须可执行，未确认项标“待确认”。

## B — 边界

### 不要在以下情况使用此卡

- 无持仓时先选入场，不归本卡。
- 浪级未定或延长信号未确认时，不拿延长目标做计划。
- 用户只要仓位比例→ `trend-position`。

### 书中警告的失败模式

- 把低一级五浪误判为延长浪（ce09）。
- 把延长浪信号当成延长浪必然发生（ce10）。
- 把“具备结束条件”当成真正结束（ce11）。
- 上破原高点仍死守空单（ce12）；第五浪末端重仓抓顶（ce21）。

### 作者盲点（阶段 0 批判）

- 延长是否成立要靠后市确认，书中无量化跟踪规则。
- 三层仓位只有原则，没有具体分配比例。
- 案例以指数为主，个股跳空/停牌会破坏止损与目标。

### 易混

- 本卡管“拿多久、目标怎么移、失败怎么反手”，不管“在哪进”和“下多少”。
- 与 `top-capture`/`bottom-capture`：顶底卡给入场点，本卡给持仓周期与退出。
- 与 `trend-position`：本卡给层级，不给比例。
