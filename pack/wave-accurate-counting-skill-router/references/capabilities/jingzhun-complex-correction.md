# 复杂调整与浪中浪（双复杂结构）

## R — 原文

> 当一浪或者三浪同时下破具备两个复杂调整结构形态的关键点时就是形成双复杂调整结构信号，那么就是顺双复杂调整之势的最佳做空或追空时机。

— 出处：第三章第三节（复杂调整浪中包含双复杂调整结构），图3-13

## I — 自述

1. 浪中浪=一个调整浪内部再含一个完整的复杂调整或复杂反弹结构；双复杂=外层复杂结构里再套一层复杂结构。
2. 不是“更复杂的剪刀/镰刀”，而是“谁包含谁”的层级关系；先定外层，再找内层。
3. 外层和内层各有一套关键点；双复杂的确认不看外形，而看两个结构的关键点是否被同一段走势同时下破。
4. 一浪或三浪同时下破两个关键点=共振，才是顺双复杂之势追空/加仓的位置。
5. 只破一个关键点=单复杂结构，不能重仓；破后快速收回=结构失败，按反手处理。
6. 止损放最近反弹高点（a 浪或 c 浪高点）外 1～2 点；目标看外层 c 浪结束。
7. 双复杂可继续演变为三组三浪或组合结构；同一段既像复杂三浪又像三组三浪时，用 c 浪是否分解、是否只是大一级 (a) 的细分来排除。
8. 无法区分时按大一级结构操作，不在小级别反复改名。
9. 双复杂共振可适当加重，但 c0 破 c2 低点这类“已具备结束条件、止损又远”的位置只能轻仓或回避。
10. 外层 c 浪具备/确立结束时是最好的抓底做多时机，止损 c 浪低点下 1～2 点；但双复杂仍可能演变，不能满仓。
11. 与单层模式库分工：模式库回答“是什么”，本卡回答“里面还套了什么、两个关键点在哪、能不能加仓”。

## A2 — 未来触发

1. “这是不是浪中浪 / 里面怎么还有结构”（Is this wave-within-wave?）
2. “为什么跌了又跌 / 怎么又破一个低点”（Why does it keep falling?）
3. “两个结构的关键点在哪”（Where are the two structures' key levels?）
4. “能不能加仓 / 现在追空吗”（Can I add? Should I chase?）
5. “这里能不能抓底”（Can I bottom-fish here?）

语言信号（中/英）：浪中浪、双复杂、嵌套调整、两个关键点、加仓追空 / wave within wave, double complex, nested correction, two key levels, add to short。

近邻负例（不归本卡）：“这是什么调整结构”→ correction-patterns；“这是三角形/组合吗”→ triangle/combination；“走完了吗”→ end-conditions；“哪里抄底/止损目标”→ bottom-capture；“这是几浪”→ wave-levels。

## E — 执行步骤

**输入契约**：外层调整结构（a/b/c 或双节棍/镰刀/剪刀）、内层复杂结构候选、至少两个关键点价格、最近反弹高点、当前价、两级以上周期数据。

1. **定外层**：按 correction-patterns 标出外层模式、a/b/c 角色、外层尚未结束的依据。完成标准：外层模式+关键点+未结束依据。
2. **找内层**：在外层某一浪内部识别完整复杂调整/反弹结构，确认它自身三浪闭合。完成标准：内层结构名+所在外层浪位+自身关键点。
3. **列双关键点**：把两个结构的关键点写成两行价格（如 a1 低点、c1 低点；a 浪低点、c2 低点），确认不是同一个点。完成标准：两行关键点表+级别标注。
4. **共振判定**：观察一浪或三浪是否同时下破两个关键点；只破一个→单复杂，不重仓；两个都破→双复杂确立，顺调整势追空/加仓。完成标准：破点顺序+确认/未确认结论。
5. **止损/目标/仓位**：止损=最近反弹高点外 1～2 点；目标=外层 c 浪结束；共振可适当加重，止损距离大则降仓；c0 破 c2 这类位置只轻仓/回避。完成标准：止损价、目标价、仓位档。
6. **转化与退出**：检查三浪/三组三浪转化（c 浪是否分解、是否只是大一级 (a) 的细分）；无法区分按大一级结构操作；外层 c 浪具备/确立结束时抓底多，止损 c 浪低点下 1～2 点；上破 a 浪高点→双复杂失败，止损/反手。完成标准：转化判定+抓底/反手条件。

**分支/判停**：只破一个→单复杂；两个都破→双复杂；破后快速收回→失败反手；c0 破 c2→轻仓；无法排除演变→按多解轻仓；数据不足→不做。

**输出契约**：外层/内层结构、双关键点价格、共振状态、追空/加仓触发、止损、目标、仓位、转化分支、抓底条件。

**完成标准**：两个关键点可复核；共振有破点顺序；单关键点未重仓；止损目标可执行；失败分支写明。

## B — 边界

**反场景**：单层模式分类、三角形、组合结构、顶部捕捉、单纯 c 浪交易。

**作者警告**：只破一个关键点不能重仓；c0 破 c2 只能轻仓/回避（ce03）；接近结束点不追空（ce01）；雏形结束条件处不追空（ce02）；双复杂仍可演变，不能当“确定性高”满仓；看不懂结构就等或不做（ce28/ce16）。

**盲点**：嵌套识别主观、案例是事后标注；书中示意图案例非真实行情；1～2 点止损对 A 股跳空/跌停不适用；目标未达时没有退出规则。

**易混**：双节棍（单层）vs 双节棍含双节棍（双复杂）；剪刀（单层）vs 剪刀在双节棍内（浪中浪）；三浪 vs 三组三浪；复杂调整 vs 组合结构；三角形嵌套归 triangle-trading。

**A股适配**：T+1、涨跌停、跳空；追空遇跌停无法成交；仓位按止损距离调整，不用固定手数。
